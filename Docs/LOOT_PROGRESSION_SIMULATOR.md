# Loot Progression Simulator

Open **Balance Workbench → Loot Progression** after selecting a Player Build and objective. A static run compares each production-generated drop to the same starting equipment. **Progressive auto-equip** replaces gear after accepted upgrades and continues the stream; the result separates first, second, third, and later inter-upgrade intervals. **Run Interval Trials** repeats that progressive stream from the same starting build with independent deterministic sub-seeds, aggregates the four interval distributions, and reports how many trials reached each upgrade number. Trials that never reach a later upgrade do not add a zero-length interval.

**Run First-Upgrade Trials** is a separate experiment: every trial clones the same starting build, takes a distinct deterministic sub-seed, and stops at its first qualifying drop or the configured kill limit. A trial with no upgrade is *censored*, not assigned an artificial upgrade at the limit. The summary reports successful-trial kill percentiles and the cumulative probability found by 10/25/50/100/250/500/1,000 kills (as applicable). The survival chart plots the fraction still waiting. Large trial counts, particularly with actual enemy gear enabled, can be expensive; use Cancel.

Encounter source modes include Fixed Rarity, Specific Enemy, Biome Population, Specific Location, Specific Combat Level, Stage Range, Full Combat-Level Loop, and Custom World Range. World modes call `WorldProgression.Resolve` for each simulated stage/level/world seed and take the resulting biome, location, archetype, and boss identity. Rarity follows authored production spawn weights. Loot budgets, currency selection, item rarity, slot, element, weapon, and affixes use production services with an injected deterministic Workbench RNG. Live game loot is unchanged. **Sample actual enemy gear** uses the production Enemy Gear Lab build path for ordinary enemies and authored boss prefabs. The sampler preserves the production enemy build and boss role; no averaged biome enemy is invented.

Results show kills, drops, upgrade frequency/magnitude, currency accumulation, slot and item-rarity counts, and per-source biome/location/stage/archetype/rarity/boss breakdown. **Export Source Breakdown CSV** includes source-specific currency stacks, slot counts, and item-rarity counts. **Inspect Best Dropped Item** shows the exact saved item.

**World Progression Sweep** samples combat levels 1–360 with configurable step, full 10-stage encounter loops per level, and optional independent first-upgrade trials. Build sources are Low/Mid/Optimized Tooling 2 gear profiles, the selected Tooling 2 profile, or the current custom build. The CSV reports gear and currency per kill, upgrade chance, expected kills per upgrade, first-upgrade median among successes, average upgrade magnitude, boss share, and Rare/Legendary share. An infinite expected interval means no upgrade was found in that sampled run, not proof upgrades are impossible.
