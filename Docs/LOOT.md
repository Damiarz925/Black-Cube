# Production loot: configured budgets and player history

`LootDropBalanceProfile.asset` owns editable per-enemy gear-copy and ordinary-currency chance budgets. For direct-rate currencies, the production order is base chance plus rarity and applicable overrides, then multipliers, then Enemy Power. Budgets above one yield guaranteed integer copies plus one fractional roll. The numeric rates in the asset are initial authoring values, not final balance. Older currencies explicitly marked legacy continue through their weighted path and must not be double-counted as direct-rate rewards. See `ENEMY_POWER_AND_LOOT.md` for the formulas, overrides, and the currently incomplete enemy-power reference population.

Live rewards use entropy-backed production RNG. The Workbench Drop Simulator and Progression History use injected deterministic RNG over the same production budget and item-generation rules. Progression History records the number and rarity of enemies a simulated player has actually encountered before generating gear and currency; it does not assume a fixed item count per slot. Item Level remains the level at which the item dropped. See `PROGRESSION_HISTORY_SIMULATION.md` and `REALISTIC_PLAYER_MODEL.md`.
