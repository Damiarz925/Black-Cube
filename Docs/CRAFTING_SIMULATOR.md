# Crafting Simulator

Open **Balance Workbench → Crafting Simulator** and select a real starting item. Set an ordered repeating policy, target conditions, seed, independent trials, and maximum actions. Ordinary actions call production `EquipmentCrafting` and `ModManager`: Normal→Magic, Magic reroll, Magic→Rare, rare/Legendary modifier add, reroll, and remove. Endgame operations are **Empowerment**, **Boss Infusion**, and **Implicit Reforge**. Ancient relic actions are not equipment crafting and are excluded. There is no separate production Legendary-reroll currency at this HEAD.

Endgame steps choose a target explicit stat and, for infusion, a production challenge. The simulator calls `EmpowermentCrafting.TryApply`, `BossSpecialCrafting.TryReplace`, and the shared production implicit-reforge mutation. Production level/rarity/side/affix/duplicate/Potential checks apply. Endgame resource quantities start at zero unless configured in **Resource Inventory**; toggle Unlimited explicitly if desired. Ordinary `Currency Budgets` retain the older convention that zero means unlimited. Successful actions consume one simulated resource, while failed eligibility checks do not. The Workbench does not alter the player's real inventory, ledger, or save.

Target groups support All Required, Any Of, and At Least N of configured normal-affix goals, plus minimum Empowered count, one specific Empowered stat, a boss-special modifier or pool/family ID, implicit family/tier/minimum roll, maximum undesirable explicit modifiers, and optional minimum selected build-objective improvement. For the latter, save the current build as the objective baseline. Results include successes/trials, Wilson 95% upper bound for zero successes, Potential/resource/progression failures, action and target-progress distributions, Potential remaining at failure, per-currency/resource consumption, best partial item, and trace. A `0 / 1,000` outcome is an analysis result, not a mandate to change game balance.

**Bounded Policy Search** expands ordered production-action sequences using a beam. Configure beam width, action depth, random outcomes per candidate, maximum evaluated states, and seed. Its score prioritizes target success and partial target progress, with minor Potential/cost tie-breakers; it is not a universal item-value function. Output is **BEST DISCOVERED POLICY**, never proven optimal. Search actions are copied from the current policy steps. **Validate Policy** reruns a discovered sequence for 1,000 or 10,000 independent trials.

Known limitations: best-failure inspection is a saved item description, not a live item inspector; trace replay is an exported recorded sequence, not an interactive step-forward debugger. The search evaluates action sequences by bounded Monte Carlo rather than exhaustively enumerating possible item states. Save/load policies as JSON and compare manually authored policies before drawing economy conclusions.
