# Production crafting and realistic-player usage

`EquipmentCrafting.CanApply` and `TryApply` are the authority for ordinary equipment crafting. They enforce item rarity, affix-side capacity, eligible target modifiers, and production Crafting Potential before an action succeeds. Currency is consumed only after success. Affix Focus can constrain Add Rare Modifier, Remove Rare Modifier, Magic Reroll, or Rare/Legendary Reroll to Prefix or Suffix; it consumes one Focus alongside the ordinary currency. See `AFFIX_FOCUS_CURRENCY.md` for the runtime UI and validation details.

The Workbench **Crafting Simulator** evaluates a specified production item, currency-action policy, target affixes, simulated budgets, and deterministic seeds. It is a controlled experiment, not a full player history. The **Progression History → Run Expected Crafting** path instead starts with the historical item inventory and one shared acquired currency stock. It estimates Craftability by sampling legal production outcomes against the selected whole-build objective and current defense deficits, crafts the best positive-expected project, then re-ranks projects after each action. Fast/Serious/Deep controls candidate and roll-sample budgets. The action trace reports item index, currency, optional focused side, Crafting Potential before/after, spent and unused currency, and stopping reason. Every original item remains available for the final gear search; Craftability does not discard low-ranked items.

The crafted-player path is a bounded stochastic look-ahead, not an optimal player policy. It currently crafts after the generated history rather than at each encounter and floors fractional expected-mode currency to spendable integers. Re-run it after changing class, weapon, objective, or defensive constraints; the Workbench invalidates stale crafting results when those settings change. Compare **Use Expected Crafting** on and off, then validate the resulting build in Combat Lab.
