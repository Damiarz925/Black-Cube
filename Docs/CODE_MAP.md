# First-party source map

Every runtime/editor C# file and art-tool C#/Python/PowerShell file is listed below. Unity tutorial, TextMesh Pro, Store Assets, Packages, Library and generated project files are excluded. Archived art tools are explicitly labeled; do not run them to update current art.

| File | Responsibility and connection |
| --- | --- |
| [Assets/Scripts/PaperEnemyAnimationSet.cs](../Assets/Scripts/PaperEnemyAnimationSet.cs) | Enemy display name, rest/attack sprites and popup anchor shared by prefab and builder. Eight attack poses use index3 impact; this asset does not set boss role, health, loot or speed. |
| [Assets/Scripts/AffixDefinitions.cs](../Assets/Scripts/AffixDefinitions.cs) | Serialized affix tiers, item-level gates and exclusion groups used by ModDatabase and ModManager. Tier generation needs a seeded first tier; tier indices are one-based. |
| [Assets/Scripts/AilmentCalculator.cs](../Assets/Scripts/AilmentCalculator.cs) | Converts eligible pre-defense hit components into per-tick strength, tick count and global-turn interval. Generic hit scaling is already in the source hit and must not be applied twice. |
| [Assets/Scripts/BattleManager.cs](../Assets/Scripts/BattleManager.cs) | Owns combat clocks, target replacement and damage resolution. Attack speeds are attacks/second at threshold 100; sprite poses only visualize this clock and never cause damage. |
| [Assets/Scripts/BleedStatusEffect.cs](../Assets/Scripts/BleedStatusEffect.cs) | Bleed asset defaults and editor validation for physical-hit damage over time. Active stacks and ticking belong to StatusController, not this shared asset. |
| [Assets/Scripts/CombatCalculator.cs](../Assets/Scripts/CombatCalculator.cs) | Pure hit and DOT mitigation shared by both sides. Evasion has no hit roll here; physical resistance currently falls through StatMappings to FireRes, an existing limitation. |
| [Assets/Scripts/DamageContext.cs](../Assets/Scripts/DamageContext.cs) | Per-attack snapshot of typed damage components and critical metadata. The components are one attack, not separate combat turns; critical scaling is applied by the attacker. |
| [Assets/Scripts/DamageNumberAccent.cs](../Assets/Scripts/DamageNumberAccent.cs) | Draws the decorative UI geometry behind styled damage numbers. Presentation only: no damage calculation or timing authority. |
| [Assets/Scripts/DamagePopup.cs](../Assets/Scripts/DamagePopup.cs) | Creates styled screen-space numbers from world-space targets; popup instances snapshot positions so target destruction does not move them. DamageReceiver has already applied life loss. |
| [Assets/Scripts/DamageReceiver.cs](../Assets/Scripts/DamageReceiver.cs) | Single entry point for already-mitigated damage and its popup. The strongest raw component chooses a mixed hit color; it does not split the life deduction into multiple hits. |
| [Assets/Scripts/DeathMenuUI.cs](../Assets/Scripts/DeathMenuUI.cs) | Displays the killer and pauses via Time.timeScale; restart delegates to GameManager. Hide/menu/quit restore time scale so later scenes do not inherit a paused clock. |
| [Assets/Scripts/EnemyAI.cs](../Assets/Scripts/EnemyAI.cs) | Builds enemy attack snapshots from generated gear and StatsComponent; BattleManager owns attack scheduling. Enemy rarity is randomly rolled separately from the HealthComponent boss role. |
| [Assets/Scripts/EnemyStatSetup.cs](../Assets/Scripts/EnemyStatSetup.cs) | Initial enemy stat buckets; AttackSpeed zero means zero increased speed, not disabled attacks. SetupForZone is a placeholder, and enemy maximum life comes from its HealthComponent prefab. |
| [Assets/Scripts/EquipmentGlyph.cs](../Assets/Scripts/EquipmentGlyph.cs) | Procedural UI silhouettes for gear slots when no icon art is needed. Used by inventory and equipped-item panels; independent of world weapon sprites. |
| [Assets/Scripts/EquipmentManager.cs](../Assets/Scripts/EquipmentManager.cs) | Transfers Gear between inventory and one slot per GearType, replacing source-owned global modifiers. Batches StatsChanged, then emits EquipmentChanged; weapon swaps also notify PlayerController. |
| [Assets/Scripts/EquipmentStatsUI.cs](../Assets/Scripts/EquipmentStatsUI.cs) | Refreshes equipped-slot glyphs, rarity borders and hover targets from EquipmentChanged. This view does not own equipment or apply modifiers. |
| [Assets/Scripts/EquippedItemHoverUI.cs](../Assets/Scripts/EquippedItemHoverUI.cs) | Bridges an equipped slot to the shared InventoryUI tooltip. Equipped items use the protected tooltip mode that disables dismantling. |
| [Assets/Scripts/GameManager.cs](../Assets/Scripts/GameManager.cs) | Session run coordinator: initializes each gameplay scene once, then consumes and restores an optional menu load request. Nine normal kills lead to stage10 boss, whose death advances the combat level. |
| [Assets/Scripts/GameSceneNames.cs](../Assets/Scripts/GameSceneNames.cs) | Shared enabled-scene names used by MainMenuUI, GameManager and DeathMenuUI transition routes. |
| [Assets/Scripts/Gear.cs](../Assets/Scripts/Gear.cs) | Runtime item state, scrap flags, local weapon values and global rolled modifiers. ApplyMods accumulates once during generation; local percentages are fractions, global rolls remain raw percentage points. |
| [Assets/Scripts/GearStatLists.cs](../Assets/Scripts/GearStatLists.cs) | Authoritative stat pools per gear slot, shared by rolling and ModDatabase editor population. Adding a stat to the enum alone does not make it rollable. |
| [Assets/Scripts/HealthComponent.cs](../Assets/Scripts/HealthComponent.cs) | Owns life, death and single-claim enemy rewards; death can synchronously cause a replacement encounter. Player life reads StatsComponent; enemy life uses serialized maxLife. |
| [Assets/Scripts/IgniteStatusEffect.cs](../Assets/Scripts/IgniteStatusEffect.cs) | Ignite/Burn asset defaults and validation for fire-hit damage over time. Shared definition only; each target owns its runtime StatusInstance. |
| [Assets/Scripts/Inventory.cs](../Assets/Scripts/Inventory.cs) | Session equipment ownership, pickup-only auto-dismantling, shared random-currency rewards and legacy Scrap migration. |
| [Assets/Scripts/CraftingCurrencySystem.cs](../Assets/Scripts/CraftingCurrencySystem.cs) | Stackable ordinary/Ancient currency, armed target validation, exact equipment crafting caps, and equipment/currency/relic inventory tabs. |
| [Assets/Scripts/GamePersistence.cs](../Assets/Scripts/GamePersistence.cs) | Versioned JSON save/load for crafted inventory, equipment, currencies, permanent relics and active relic slots; owns the one-shot menu load request. `TrySave` exposes current V1 success/failure to save-gated exits without expanding the schema. |
| [Assets/Scripts/RelicSystem.cs](../Assets/Scripts/RelicSystem.cs) | Explicit level-50 rebirth, permanent/current-cycle relic ownership, Ancient crafting, active-slot multipliers and relic UI. |
| [Assets/Scripts/InventoryFilterUI.cs](../Assets/Scripts/InventoryFilterUI.cs) | Builds the pickup-filter controls and edits Inventory cutoff settings. Enabled level/rarity cutoffs combine with OR; existing inventory is not retroactively scrapped. |
| [Assets/Scripts/InventoryUI.cs](../Assets/Scripts/InventoryUI.cs) | Maintains Gear-to-slot views and a shared root-canvas tooltip, with a responsive scrolling grid. Subscribes to inventory changes while enabled and preserves unchanged slot objects. |
| [Assets/Scripts/ItemSlotUI.cs](../Assets/Scripts/ItemSlotUI.cs) | Binds a Gear to its grid button, rarity visuals and pointer actions. Left click equips, right click requests dismantling; Inventory remains the authority for allowed actions. |
| [Assets/Scripts/ItemTooltipUI.cs](../Assets/Scripts/ItemTooltipUI.cs) | Formats actual local/global item values and owns hover-card scrolling/placement. Revalidates ownership before scrapping and closes when the item or anchor disappears. |
| [Assets/Scripts/LevelGenerator.cs](../Assets/Scripts/LevelGenerator.cs) | Legacy 3D placement planner using theme prefab lists and world-space anchors. It builds data, not GameObjects; ZoneManager applies plans, and the paper scene disables this path. |
| [Assets/Scripts/LevelPlan.cs](../Assets/Scripts/LevelPlan.cs) | Data passed from LevelGenerator to ZoneManager: theme, seed, bounds and placement lists. Bounds/foreground fields are not all enforced or consumed by the current planner. |
| [Assets/Scripts/LootManager.cs](../Assets/Scripts/LootManager.cs) | Rolls item type/rarity/element and delegates affixes to ModManager, then returns one Gear to GameManager. Item level uses combat level plus enemy-rarity bonus. |
| [Assets/Scripts/MainMenuUI.cs](../Assets/Scripts/MainMenuUI.cs) | Menu transition callbacks: New Game clears stale load intent, while Load Game requests restoration of the current snapshot before opening gameplay. Options exposes the persisted passive-tree pause toggle; Achievements remains a placeholder. |
| [Assets/Scripts/GameplayOptions.cs](../Assets/Scripts/GameplayOptions.cs) | Persisted, default-off menu pause preferences keyed by window type so later menus can opt in without changing today’s behavior. |
| [Assets/Scripts/ModDatabase.cs](../Assets/Scripts/ModDatabase.cs) | Serialized affix catalog with lazy enum/id lookups. Editor validation fills missing definitions and allowed slots; configured tier ranges remain the balancing data. |
| [Assets/Scripts/ModManager.cs](../Assets/Scripts/ModManager.cs) | Weighted stat and tier selection, item-level gating and duplicate-group exclusion. Weapon base damage/speed/crit are guaranteed rolls outside the random affix count. |
| [Assets/Scripts/PaperBattleHUD.cs](../Assets/Scripts/PaperBattleHUD.cs) | Reads run, health and current-enemy state, coordinates mutually exclusive gameplay overlays, and owns the canonical `Time.timeScale` pause/play entry points used by PauseMenuUI. |
| [Assets/Scripts/PauseMenuUI.cs](../Assets/Scripts/PauseMenuUI.cs) | Runtime-built pause/options overlay with Resume, Options, Save & Main Menu, and Save & Quit. Exit actions share `GamePersistence.TrySave` and remain paused on failure. |
| [Assets/Scripts/PaperPlayerAnimationSet.cs](../Assets/Scripts/PaperPlayerAnimationSet.cs) | Shared serialized player idle/attack frames and matching hand anchors. Eight attack slots follow PaperSpriteActor impact conventions; idle speed is frames/second. |
| [Assets/Scripts/PaperSpriteActor.cs](../Assets/Scripts/PaperSpriteActor.cs) | Presentation layer for authored idle and attack cels plus legacy four-pose actors. Attachment positions use body-local Unity units, angles use degrees; empty player equipment hides the entire weapon. |
| [Assets/Scripts/PaperWeaponVisual.cs](../Assets/Scripts/PaperWeaponVisual.cs) | Whole weapon sprite profile, including handle, with pivot correction and scale. Sprite art points along +X; gripOffset is measured in sprite-local world units before scale/rotation. |
| [Assets/Scripts/PlayerController.cs](../Assets/Scripts/PlayerController.cs) | Builds deterministic noncritical previews and randomized actual attacks from equipment/stats. EquipWeapon publishes AttackChanged for UI/art; EquipmentManager applies the global item modifiers. |
| [Assets/Scripts/PlayerProgression.cs](../Assets/Scripts/PlayerProgression.cs) | Session XP, level cap, 290 binary passive allocations, connectivity-safe refunds, ordinary stat binding, and keystone state projection on GameManager. |
| [Assets/Scripts/PassiveKeystoneState.cs](../Assets/Scripts/PassiveKeystoneState.cs) | Recomputed inner/outer keystone mechanics across outgoing hits, ailments, stack caps, defenses, resources, speed, costs, and chance rolls. |
| [Assets/Scripts/PlayerStatSetup.cs](../Assets/Scripts/PlayerStatSetup.cs) | Early player baseline setup before health Awake reads Life. Values entering StatsComponent use raw units: Life is HP and percentage buckets use percentage points. |
| [Assets/Scripts/PlayerStatsPanelUI.cs](../Assets/Scripts/PlayerStatsPanelUI.cs) | Rebuilds categorized stat rows on StatsChanged/AttackChanged while retaining collapsed sections. Attack previews use the noncritical context so inspecting stats does not consume random rolls. |
| [Assets/Scripts/PoisonStatusEffect.cs](../Assets/Scripts/PoisonStatusEffect.cs) | Poison asset defaults and validation. Eligible source damage is selected centrally in AilmentCalculator; stack instances belong to the target. |
| [Assets/Scripts/Pool.cs](../Assets/Scripts/Pool.cs) | Legacy scenery reuse by string key. ZoneManager sets placement and activation after Get; Release deactivates and returns the object to its key stack. |
| [Assets/Scripts/PooledObject.cs](../Assets/Scripts/PooledObject.cs) | Stores the pool key assigned by Pool.Get so Release returns scenery to the correct stack. |
| [Assets/Scripts/RolledMod.cs](../Assets/Scripts/RolledMod.cs) | One resolved affix: StatTypes key, one-based tier and raw numeric roll. Gear routes this value into local weapon fields or global modifiers. |
| [Assets/Scripts/SkillTreeUI.cs](../Assets/Scripts/SkillTreeUI.cs) | Builds the 290-node spoke/bridge/ring/keystone panel, displays full effects, allocates/refunds, and provides pan plus extended zoom. |
| [Assets/Scripts/SpawnAnchorGroup.cs](../Assets/Scripts/SpawnAnchorGroup.cs) | Serialized world transforms for legacy 3D scenery categories. LevelGenerator samples these anchors; they do not control combat enemy spawns. |
| [Assets/Scripts/StatCategory.cs](../Assets/Scripts/StatCategory.cs) | UI grouping labels used by StatCategoryMapping; these categories have no effect on combat formulas. |
| [Assets/Scripts/StatCategoryMapping.cs](../Assets/Scripts/StatCategoryMapping.cs) | Maps stat enum members to display sections and labels. Explicit cases depend on names, not enum ordering; newly added stats need an intentional display category. |
| [Assets/Scripts/StatDisplayFormatting.cs](../Assets/Scripts/StatDisplayFormatting.cs) | Friendly names and raw-value formatting for stats and tooltips. Percent classification must agree with StatsComponent; display formatting never changes gameplay units. |
| [Assets/Scripts/StatHeaderUI.cs](../Assets/Scripts/StatHeaderUI.cs) | Small serialized TMP label binding for a stats section heading; PlayerStatsPanelUI creates and manages these views. |
| [Assets/Scripts/StatMappings.cs](../Assets/Scripts/StatMappings.cs) | Maps damage elements to stat keys for attacker scaling and defender mitigation. Unsupported elements use fallback keys; physical resistance currently maps to FireRes even in the hit pipeline. |
| [Assets/Scripts/StatModifiers.cs](../Assets/Scripts/StatModifiers.cs) | Stat operations and a modifier source token used for removal on gear/skill changes. Most values are raw points; non-bucket multiplicative operations take a fractional multiplier delta. |
| [Assets/Scripts/StatRowUI.cs](../Assets/Scripts/StatRowUI.cs) | Binds a stat name/value pair to serialized TMP labels. Formatting and which rows exist are decided by PlayerStatsPanelUI. |
| [Assets/Scripts/StatsComponent.cs](../Assets/Scripts/StatsComponent.cs) | Actor stat store with cached StatValue entries and batched change events. GetStat converts classified percent points to fractions; GetRawStat preserves stored units. |
| [Assets/Scripts/StatTypes.cs](../Assets/Scripts/StatTypes.cs) | Serialized stat identifiers consumed by gear catalogs, formulas and UI. Preserve numeric identities when extending; presence in this enum does not imply an implemented mechanic. |
| [Assets/Scripts/StatusBadge.cs](../Assets/Scripts/StatusBadge.cs) | Pointer target for one status summary in StatusHUD. Hover delegates to the HUD tooltip rather than changing the status model. |
| [Assets/Scripts/StatusController.cs](../Assets/Scripts/StatusController.cs) | Target-owned stacks with global-turn ticking and pending effect aggregation. Mutation is separated from application because damage/death callbacks can clear statuses or replace targets. |
| [Assets/Scripts/StatusController.Display.cs](../Assets/Scripts/StatusController.Display.cs) | Produces per-effect, frequency-weighted summaries for status UI and the shared per-stack tick calculation. This partial class participates in damage math as well as display. |
| [Assets/Scripts/StatusEffects.cs](../Assets/Scripts/StatusEffects.cs) | Shared status definition and element/mask enums. Magnitude is a coefficient and duration/interval are global turns; virtual callbacks are extension hooks not dispatched by current ticking. |
| [Assets/Scripts/StatusGlyph.cs](../Assets/Scripts/StatusGlyph.cs) | Procedural UI glyph for a status kind. Rebuilds mesh through Unity UI; status strength, eligibility and duration live in the model. |
| [Assets/Scripts/StatusHUD.cs](../Assets/Scripts/StatusHUD.cs) | Builds player/enemy status strips and hover tooltips from StatusController summaries. Rebinds to the current spawned enemy and discards stale badges on target replacement. |
| [Assets/Scripts/StatusInstance.cs](../Assets/Scripts/StatusInstance.cs) | Mutable lifetime, stack strength and source-stat reference for one applied effect. Interval >0 ticks every N global turns; <=0 allows 1-interval ticks per turn. |
| [Assets/Scripts/StatValue.cs](../Assets/Scripts/StatValue.cs) | Caches one raw stat bucket and invalidates on base/modifier changes. Result is (base + flat + additive) times multiplicative; more-percent buckets multiply each roll and expose the effective percentage. |
