# Production Weapon Skills (Step 18)

All values below are **first-pass placeholders**, not final balance. `PlayerSkillDefinition.CreateProductionDefaults` is the authoritative data source. Every weapon has exactly two stable production IDs; legacy skill enum values remain readable and are not reused.

| Weapon | Skill | Cast mode | First-pass behavior |
|---|---|---|---|
| Sword | `skill.sword.rapid_flurry` | QueuedAttackReplacement | 3 independent 100% hits; +1 per 50% bonus Attack Speed; 8 cap; one attack-gauge event. |
| Sword | `skill.sword.armour_strike` | QueuedAttackReplacement | 150% base; 2% more per 100 Armour, capped at 200% armour-derived more. |
| Two-Handed Axe | `skill.axe.rage_strike` | QueuedAttackReplacement | 150% hit; Rage generated by this event is multiplied by 1.5; compatible with Rage Finisher. |
| Two-Handed Axe | `skill.axe.hemorrhage` | QueuedAttackReplacement | 60% direct hit; guaranteed Bleed uses 300% of the ordinary would-be hit basis. |
| Bow | `skill.bow.venom_shot` | QueuedAttackReplacement | Traveling projectile; zero direct damage; guaranteed Poison uses 300% virtual hit basis. |
| Bow | `skill.bow.double_volley` | QueuedAttackReplacement | Doubles final projectile count, retaining independent travel/fizzle. |
| Staff | `skill.staff.fireball` | AutoCooldown | 250% Fire, 60 Mana, 5s base cooldown. |
| Staff | `skill.staff.shock_barrage` | AutoCooldown | 100% Lightning per hit, 50 Mana, 5s; 1 + floor(combined Shock/20pp), capped at 6 and snapshotted at cast. |
| Sceptre | `skill.sceptre.restorative_strike` | QueuedAttackReplacement | 100% hit; heals 35% of actual post-mitigation damage. |
| Sceptre | `skill.sceptre.frost_judgment` | QueuedAttackReplacement | Chilled target rolls Freeze from Chill strength; Frozen target Shatters. |
| Dagger | `skill.dagger.backstab` | QueuedAttackReplacement | 150% hit; normal independent Bleed and Poison chance rolls. |
| Dagger | `skill.dagger.quick_strike` | ImmediateCooldown | Immediate 100% off-gauge attack, 25 Mana, 4s base cooldown. |

Cooldown Reduction is stable stat ID 126. Effective cooldown is `max(0.20, base / (1 + CDR))`. Attack Speed never modifies cooldown; CDR never modifies the normal attack gauge. Deprecated Cast Speed remains ID 120 solely for serialized safety and legacy developer fixtures.

Freeze stores the applying Chill strength and skips exactly the enemy's next attack opportunity. Shatter consumes Freeze and creates a Cold burst with `3.0 + 4.0 × storedChill01`; it does not scale from target maximum Life.

Secondary damage uses `CombatEventTags`. Heal-to-Harm carries `TriggerlessDamage`, `HealConvertedDamage`, and `NoSecondaryTriggers`; Eruption, Shatter, and Rupture have distinct identities so recursive proc chains can be rejected centrally.
