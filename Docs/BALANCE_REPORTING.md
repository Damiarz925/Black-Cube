# Balance Reporting

Configure scenarios in **Balance Snapshots**, then open **Balance Report**. Create ordered sections with titles and designer notes. Each widget references a saved scenario name and chooses **Live Current Results** or **Saved Snapshot Results**. The widget catalog includes notes, single metrics/tables, curve charts, histograms, matchup matrices, sensitivity/affix/passive rankings, loot/currency tables, crafting summaries, breakpoint lists, and snapshot regression summaries. The current renderer uses the captured scenario's data shape; some specialized catalog labels still use generic metric/table presentation rather than a dedicated layout.

**Run Report** executes live widgets through the same snapshot scenario service or reads the selected saved snapshot. Progress advances per widget, and Cancel marks a run partial. The report bundle under `ReviewCaptures/BalanceWorkbench` contains `Report.md`, `Charts/*.png` for curves and histograms, `Data/*.csv` for populated numeric widgets and regression tables, and `metadata.json`. Markdown includes source/status per widget and notes missing/stale/failed or incompatible results. A regression-summary widget compares the selected Before snapshot to fresh production results. Presets can be saved/loaded as JSON. No report action changes production balance data.

Review scenario configurations and fingerprints before comparing historical snapshots. A saved snapshot with a different production-data fingerprint is labeled **STALE**, not silently refreshed.
