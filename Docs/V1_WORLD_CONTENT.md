# V1 World Content

Step 19 replaces the Step 15 placeholder catalog with the authoritative V1 mechanical catalog. The world remains six biomes, ten base locations per biome, six corruption tiers, and ten encounters per combat level: 360 combat levels and 3,600 structurally resolvable stages.

| Biome | Levels | Mechanical identity |
|---|---:|---|
| Ashen March | 1–60 | Physical, Armour, Bleed, fundamentals |
| Cinder Wastes | 61–120 | Fire, Ignite, burst, eruption |
| Frostbound Reaches | 121–180 | Cold, Chill, control and freeze safety |
| Tempest Heights | 181–240 | Lightning, Shock, speed and multi-hit |
| Voidfen | 241–300 | Void, Poison and corruption |
| Black Citadel | 301–360 | Hybrid culmination |

Each biome owns ten named locations, eight non-boss archetypes, ten main bosses, reusable ordinary/elite skill loadouts, and an element/build-preference profile. Each location owns a stable encounter table and mechanical profile. Encounter selection is deterministic from stable world seed, combat level, stage, and table identity. Reward generation remains on the separate Step 18.6 entropy-backed loot stream.

Corruption profiles at 0/20/40/60/80/100% centrally add pressure, speed, recovery, cadence, and apex mechanic hooks. The same location boss is recognizable across corruption variants; the corruption profile provides the evolution instead of duplicating the boss identity.

The current paper combat scene intentionally uses Goblin/Hobgoblin-compatible presentation fallbacks for the production mechanical identities. Final enemy art, animation, audio, and environment presentation remain manual content work.
